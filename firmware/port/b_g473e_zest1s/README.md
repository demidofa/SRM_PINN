# Прошивка для платы управления B-G473E-ZEST1S (STM32G473QET6), ВИД 8/6

Плата управления B-G473E-ZEST1S на базе микроконтроллера STM32G473QET6 (Arm Cortex-M4F, 512 КБ Flash,
128 КБ SRAM), встроенный отладчик STLINK-V3EC. Порт ядра `firmware/core` для четырехфазного ВИД 8/6.

## Силовая часть

Силовая плата STEVAL-LVLP01 из комплекта ZeST содержит три полумоста (драйвер STDRIVE101) и
предназначена для трехфазных бесколлекторных двигателей. Для ВИД 8/6 она не подходит: нужны четыре
несимметричных моста, в каждом из которых верхний и нижний ключи фазы управляются независимо.
Силовой модуль ВИД подключается к разъему MC connector V2 (CN5) через адаптер B-ZEST-ADAPT1
или собственную переходную плату.

## Назначение сигналов (UM3118 Rev 3, разъем CN5)

| Сигнал | Вывод | Периферия | Контакт CN5 |
|---|---|---|---|
| Фаза A, верхний ключ | PC6 | TIM8_CH1 (AF4) | A-13 |
| Фаза B, верхний ключ | PC7 | TIM8_CH2 (AF4) | A-14 |
| Фаза C, верхний ключ | PC8 | TIM8_CH3 (AF4) | A-15 |
| Фаза A, нижний ключ | PE9 | TIM1_CH1 (AF2) | A-38 |
| Фаза B, нижний ключ | PE11 | TIM1_CH2 (AF2) | A-39 |
| Фаза C, нижний ключ | PE13 | TIM1_CH3 (AF2) | A-40 |
| Фаза D, верхний ключ | PF12 | TIM20_CH1 (AF2) | A-58 |
| Фаза D, нижний ключ | PF13 | TIM20_CH2 (AF2) | A-59 |
| Ток фазы A | PC2 | ADC1_IN8 | A-47 |
| Ток фазы B | PC3 | ADC1_IN9 | A-48 |
| Ток фазы C | PA1 | ADC1_IN2 | B-29 |
| Ток фазы D | PA2 | ADC1_IN3 | B-30 |
| Напряжение звена | PC0 | ADC2_IN6 | A-54 |
| Энкодер A / B | PF6 / PF7 | TIM5_CH1 / CH2 (AF6) | B-16 / B-17 |
| Разрешение силового модуля | PG7, PG6 | GPIO | A-16, A-41 |

Альтернативные функции сверены с базой ST STM32_open_pin_data. PA1 и PA2 используются в конфигурации
перемычек по умолчанию (SB4, SB23 установлены). Три таймера ШИМ запускаются одновременно с общим
нулем счетчика; АЦП запускаются от TIM1 (TRGO2) каждые два периода ШИМ, 10 кГц.

## Сборка и работа

```
make vendor        # загрузка CMSIS и HAL STM32G4 из GitHub
make               # сборка: build/srm_fw.elf и build/srm_fw.bin
make flash         # запись через st-flash (или STM32CubeProgrammer)
```

Проект собирается без ошибок и предупреждений (около 21,1 КБ Flash, 6,8 КБ RAM). После сброса
прошивка калибрует нули датчиков тока, выставляет ротор и ожидает нажатия кнопки B2; задание
скорости — переменная `g_speed_ref_rpm`, длительность прерывания — `g_isr_us`, `g_isr_us_max`.

## Безопасность

Коэффициенты датчиков тока и напряжения в `Inc/board.h` задать по схеме силового модуля.
Входы аварийного отключения таймеров (BKIN: PB7, PA15, PF9) подключить после проверки полярности
сигнала аварии силового модуля. Первые включения выполнять при пониженном напряжении звена
через источник с ограничением тока.
