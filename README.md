# Открытые цифровые материалы дисциплины «Электромоторы»
Сквозной объект изучения: вентильно-индукторный электропривод (ВИП). Материалы согласованы с учебником
«Вентильно-индукторный электропривод» (Алямкин Д.И., Анучин А.С., Демидова Г.Л. и др.; М.: Издательский дом МЭИ).

Требования: Python 3.10+ с NumPy, SciPy, Matplotlib (для ноутбуков также pandas); компилятор C для папок embedded и firmware; для прошивки стенда — Code Composer Studio и C2000Ware, для порта STM32 — arm-none-eabi-gcc, для эмуляции — qemu-system-arm.
Все скрипты проверены; параметры учебной модели ВИД 6/4 иллюстративные.

| Папка | Содержание |
|---|---|
| `trainers/` | Два интерактивных тренажера (HTML, открываются в браузере без установки): цикл преобразования энергии; адаптация модели при управлении с прогнозированием |
| `scripts/` | Учебная модель `srm_model.py`, иллюстрации `make_figures.py`, пример ФИНС `lab1_pinn_demo.py`, онлайн-идентификация `srm_adapt.py`, озвучивание пульсаций `sound_of_srm.py` |
| `embedded/` | Экспорт ФИНС в код на языке C и проверка на ПК: `python export_to_c.py`, затем `gcc -O2 -o test_host test_host.c srm_flux_nn.c -lm && ./test_host` |
| `firmware/` | Прошивка системы управления: ядро на C11 (`core/`), проверка на ПК и на эмулируемом Cortex-M4F (`sim/`), порты для TMS320F28379D (`port/tms320f28379d/`, лабораторный стенд с ВИД 8/6) и NUCLEO-G474RE (`port/stm32g474/`, модель 6/4); подробности в `firmware/README.md` |
| `detective/` | «Неисправный привод»: генератор вариантов `make_cases.py`, проверка ответов `check_answers.py`, шесть примеров в `cases/` |
| `autograder/` | Автопроверка требований ЛР: `python check_lab.py lab2 путь/к/results/lab2`; шаблон GitHub Actions (материалы размещаются в папке `course/` репозитория обучающегося) |
| `notebooks/` | Ноутбуки ЛР1–ЛР4 для Google Colab; формируют папку `results/` для автопроверки |
| `figs/`, `sound/` | Иллюстрации к РПД (оформлены модулем `scripts/mstyle.py` в стиле рисунков учебника) и звуковые файлы |
| `instructor/` | Только для преподавателя: ответы к вариантам неисправностей, эталонные решения для проверки автопроверки. Перед публикацией репозитория для обучающихся эту папку удалить |

Проверка согласованности модели после изменений в `srm_model.py`: момент по формуле должен совпадать
с численной производной коэнергии, средний момент — с энергией цикла, умноженной на число рабочих ходов
за оборот и деленной на 2π.
