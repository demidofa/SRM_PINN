# Скрипты дисциплины «Электромоторы» (сквозной объект: вентильно-индукторный привод)

Требования: Python 3.10+, NumPy, SciPy, Matplotlib. Работает локально и в Google Colab.

| Файл | Назначение | Где используется |
|---|---|---|
| `srm_model.py` | Учебная аналитическая модель ВИД 6/4: поверхность намагничивания, момент через коэнергию, обращение ψ(i), моделирование трех фаз с несимметричными мостами (релейный регулятор, прогнозирование на один шаг), векторизованный расчет цикла в угловой области | Все лабораторные работы |
| `make_figures.py` | Иллюстрации курса: профиль индуктивности, цикл преобразования энергии, токи и момент, предельная механическая характеристика с оптимальными углами, сравнение регуляторов, бездатчиковая оценка угла | Лекции, ЛР2–ЛР4 |
| `lab1_pinn_demo.py` | Нейросеть без ограничений и ФИНС на данных «стенда» с неизмеренной областью малых токов | ЛР1 |
| `sound_of_srm.py` | Озвучивание пульсаций момента для разных регуляторов (WAV) | ЛР3, лекция 6 |

Параметры модели иллюстративные и не соответствуют конкретному серийному двигателю.
В ЛР1 обучающиеся заменяют синтетические данные экспериментальными данными стенда.

Проверка согласованности модели (выполнять после любых изменений в `srm_model.py`):
момент, вычисленный по формуле, должен совпадать с численной производной коэнергии,
а средний момент — с площадью цикла ψ(i), умноженной на число рабочих ходов за оборот
и деленной на 2π.
