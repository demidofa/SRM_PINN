# Прошивка системы управления вентильно-индукторным приводом

Учебный проект дисциплины «Электромоторы». Ядро управления написано на C11 без зависимостей от
контроллера и работает с четырехфазным ВИД 8/6 лабораторного стенда (TMS320F28379D или B-G473E-ZEST1S) и с
учебной моделью 6/4 (дополнительный порт для NUCLEO-G474RE). Проверка: на ПК вместе с моделью объекта,
на эмулируемом Cortex-M4F, синтаксическая проверка порта C2000 и полная сборка прошивки для STM32.

## Состав

| Папка | Содержание |
|---|---|
| `core/` | `srm_ctrl.c/h` — шаг регулятора (защиты, регулятор скорости, окна коммутации, релейный и прогнозирующий регуляторы тока, наблюдатель потокосцепления, чередование ключей); `srm_lut.c/h` — таблица Ψ(θ, i) с билинейной интерполяцией и онлайн-коррекцией; `srm_lut_data.c` — таблицы; `srm_config.h` — параметры; `bsp.h` — интерфейс платы |
| `sim/` | Проверка на ПК: модель объекта `plant.c` (ВИД, звено постоянного тока, механика), тесты `test_firmware.c`, сравнение с Python `compare_python.py`; `sim/qemu/` — те же тесты на эмулируемом Cortex-M4F |
| `port/tms320f28379d/` | Прошивка стенда для LAUNCHXL-F28379D (C2000Ware driverlib): четыре модуля ePWM (A — верхний ключ, B — нижний), АЦП с запуском от ePWM1, eQEP, аварийное отключение, выставка ротора, измерение длительности прерывания; сборка в Code Composer Studio (см. README порта) |
| `port/b_g473e_zest1s/` | Прошивка стенда для платы управления B-G473E-ZEST1S на базе STM32G473QET6 (ВИД 8/6): TIM8, TIM1, TIM20 — восемь независимых выходов ШИМ, АЦП1 и АЦП2, энкодер на TIM5; сборка arm-none-eabi-gcc (см. README порта) |
| `port/stm32g474/` | Дополнительный порт для NUCLEO-G474RE на HAL (модель 6/4): ШИМ 20 кГц (TIM1 — верхние ключи, TIM8 — нижние), АЦП с запуском от TIM1, энкодер на TIM4, калибровка нулей, выставка ротора, измерение длительности прерывания (DWT) |
| `tools/` | `gen_lut.py` — таблицы для прошивки из модели; `make_fw_figures.py`, `make_stand_scheme.py` — рисунки |

## Проверка

```
cd sim && make test MOTOR=8_6       # ПК: двигатель стенда 8/6, тесты и сравнение с Python
cd sim && make test                 # ПК: учебная модель 6/4
cd sim/qemu && make run MOTOR=8_6   # Cortex-M4F в QEMU (arm-none-eabi-gcc, qemu-system-arm)
cd port/tms320f28379d && ./check_syntax.sh <путь к c2000ware-core-sdk>   # проверка порта C2000
cd port/b_g473e_zest1s && make vendor && make   # прошивка B-G473E-ZEST1S (исходники ST и ARM из GitHub)
cd port/stm32g474 && make vendor && make        # прошивка NUCLEO-G474RE
```

Результаты на момент публикации:
- расхождение среднеквадратичного отклонения тока прошивки и модели Python: 0,012 А (6/4) и 0,018 А (8/6)
  при норме 0,02 А; на эмулируемом Cortex-M4F результаты совпадают с ПК;
- контур скорости: перерегулирование 1,8 % (6/4) и 1,0 % (8/6), провал скорости при набросе 5 Н·м —
  6,1 % и 4,3 %; защиты по току и перенапряжению срабатывают в том же периоде регулятора;
- шаг регулятора — около 970 (3 фазы) и 1250 (4 фазы) машинных команд в эмуляторе Cortex-M4F;
- ядро компилируется без предупреждений при 16-битном int (как у C28x), порт TMS320F28379D проходит
  проверку по заголовкам C2000Ware; прошивка B-G473E-ZEST1S (8/6) — 21,1 КБ Flash, 6,8 КБ RAM; NUCLEO-G474RE (6/4) — 20,6 КБ Flash, 6,6 КБ RAM.
Точное время на контроллере измеряется переменными `g_isr_us`, `g_isr_us_max`.

## Безопасность

Параметры и назначение выводов в `board.h` портов необходимо сверить со схемой
силового модуля и платы контроллера. Первые включения выполнять при пониженном напряжении звена
постоянного тока через источник с ограничением тока. Аппаратная защита по току (вход TZ модулей ePWM или BKIN
таймеров STM32) в силовом модуле обязательна: программная защита ее не заменяет.
