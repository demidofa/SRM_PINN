# Прошивка для TMS320F28379D (LAUNCHXL-F28379D), ВИД 8/6

Порт ядра `firmware/core` на цифровой сигнальный контроллер TMS320F28379D семейства C2000.
Используются четыре модуля ePWM (по одному на фазу: выход A — верхний ключ, выход B — нижний),
АЦП A с запуском от ePWM1, eQEP1 для энкодера и CPU Timer 1 для измерения длительности прерывания.

## Сборка в Code Composer Studio

1. Установить C2000Ware и Code Composer Studio.
2. Импортировать пустой проект driverlib: `C2000Ware/driverlib/f2837xd/examples/cpu1/empty_projects`.
3. Заменить `empty_driverlib_main.c` файлами `main.c` и `bsp_f28379d.c`, добавить в проект
   `firmware/core/srm_ctrl.c`, `srm_lut.c`, `srm_lut_data.c`.
4. В свойствах проекта: путь поиска заголовков `firmware/core` и текущая папка; определения
   `SRM_MOTOR_8_6`, `_LAUNCHXL_F28379D`; конфигурация `CPU1_FLASH` для записи во Flash.
5. Таблицу `srm_lut_data.c` заменить таблицей поверхности намагничивания двигателя стенда,
   полученной в ЛР1 (`firmware/tools/gen_lut.py` показывает формат).

## Работа

После сброса прошивка усредняет нули датчиков тока (0,5 с), выставляет ротор подачей напряжения
на фазу A (1 с) и ожидает команды. В окне Expressions установить `g_start_request = 1`;
задание скорости — `g_speed_ref_rpm`; наблюдение — `g_state`, `g_n_rpm`, `g_ia`, `g_udc`,
`g_fault`, `g_isr_us`, `g_isr_us_max`.

## Проверка без платы

Ядро с настройкой `SRM_MOTOR_8_6` проверяется на ПК: `make -C ../../sim test MOTOR=8_6`.
Код порта проверяется на синтаксис по заголовкам C2000Ware скриптом `check_syntax.sh`
(компилятор ПК; 16-битный тип int контроллера C28x при этом не моделируется).

## Безопасность

Назначение выводов сверить со схемой платы и силового модуля. Вход TZ1 модулей ePWM
подключить к аппаратной защите по току силового модуля (через X-BAR). Первые включения
выполнять при пониженном напряжении звена через источник с ограничением тока.
